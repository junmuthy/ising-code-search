# Package manifest

| Path | Purpose |
| --- | --- |
| `README.md` | Human-readable overview and basis caveat. |
| `DATA_DICTIONARY.md` | Shape and meaning of every NPZ array. |
| `PROVENANCE.md` | Published citation, local lineage, and evidence boundary. |
| `CITATION.bib` | BibTeX citation. |
| `bb64_complete.npz` | Complete machine-readable matrix bundle. |
| `code_metadata.json` | Supports, weights, conventions, and compact code specification. |
| `reconstruct_code.py` | Standalone reconstruction from the twisted-torus polynomial. |
| `verify_package.py` | NumPy-only algebraic verification suite. |
| `requirements.txt` | Minimal runtime dependency. |
| `matrices_csv/` | Human-readable copies of the principal matrices. |
| `provenance/` | Original NPZ and JSON outputs used to construct this handoff. |
| `source_analysis_scripts/` | Original local analysis/search programs. |
| `tools/build_package.py` | Script used to derive and serialize the handoff matrices. |
| `SHA256SUMS` | Integrity hashes for every other file in the archive. |
