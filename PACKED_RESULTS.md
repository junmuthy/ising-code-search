# Packed `C_8 x C_4` Ising-code search

Search date: 2026-08-24

## Target logical module

The physical lift group is

\[
G=C_{8m}\times C_4,
\]

with thickness subgroup `D = <x^8>` of order `m`.  On each BB half, the
required 32 logical fibres are

\[
z_{a,b}=x^a y^b\left(1+x^8+\cdots+x^{8(m-1)}\right),
\qquad (a,b)\in C_8\times C_4.
\]

The acceptance tests require exact CSS self-duality, exactly 64 logical
qubits, completeness and pairwise disjointness of the 64 fibres across both
BB halves, a connected Tanner graph, and the regular logical action of
`C_8 x C_4`.

## Weight-eight obstruction

The two-pair family

\[
a=(1+x^{8r})+x^u y^v(1+x^{8s})
\]

has only two quotient locations, `0` and `(u mod 8, v)`.  Their differences
generate a cyclic subgroup of `C_8 x C_4`, whose index is at least four.
Consequently its Tanner graph cannot be connected over the complete 2D
logical quotient.

The exhaustive `m=7` sweep contained 502 symmetry representatives:

- 42 had accidental logical sectors and failed `k=64`;
- 460 had exactly the intended logical module but split into at least four
  Tanner components;
- no weight-eight representative passed the full architecture screen.

## Connected weight-twelve family

The minimal connected extension uses three paired terms at quotient locations
that generate both logical directions:

\[
\begin{aligned}
a={}&(1+x^{8r_0})
 +x^{1+8p_1}(1+x^{8r_1})\\
 &+x^{8p_2}y(1+x^{8r_2}).
\end{aligned}
\]

For `m=7`, 1,323 symmetry representatives were searched.  Of these, 1,293
passed every algebraic and connectivity test; the other 30 had additional
logical sectors.

Exact integer-programming distance certificates were computed for 24 selected
accepted representatives:

- 22 have distance 7;
- 2 have distance 6.

Every canonical fibre has weight 7, so `d <= 7`.  The distance-seven results
therefore attain the distance ceiling imposed by the required disjoint fibre
representatives.

## Recommended instance

Take `m=7`, with `x^56 = y^4 = 1`, and

\[
\boxed{
a=(1+x^8)+x(1+x^{24})+x^8y(1+x^{16})
}
\]

or, expanded,

\[
a=1+x+x^8+x^8y+x^{24}y+x^{25}.
\]

With `b=a^dagger`, the minimal BB/GALA construction gives

\[
\boxed{[[448,64,7]]},
\qquad H_X=H_Z=[A\mid A^T].
\]

Its certified properties are:

| Property | Result |
|---|---:|
| Physical qubits | `448` |
| Logical qubits | `64` |
| Exact distance | `7` |
| Check weight | `12` |
| Qubit degree per CSS type | `6` |
| Rank of `H_X=H_Z` | `192` |
| Logical fibres | `32` per physical half |
| Fibre weight | `7` |
| Cross-fibre overlap | `0` |
| Tanner graph | connected |
| Logical translations | regular `C_8 x C_4` on each half |
| Physical `x`, `y` translations | verified stabilizer automorphisms |
| Half-swap plus inversion | verified stabilizer automorphism |

The exact distance calculation minimizes over one logical fibre on each
physical half.  Translation symmetry relates all 32 fibres within a half, and
the 64 fibres form a complete orthonormal logical basis.  Both representative
minimum weights are 7, proving global distance 7.

## Square-lattice bond matchings

Label the even checkerboard sublattice by the translation subgroup generated
by

\[
X=(1,1),\qquad Y=(0,2),
\]

so that it is a `C_8 x C_4` torsor.  If the east-neighbor matching is used to
identify the odd sublattice with the same torsor, the four nearest-neighbor
matchings require the following logical shifts on the odd block:

| Bond direction | Logical shift |
|---|---|
| East | `I` |
| West | `X^-2 Y` |
| North | `X^-1 Y` |
| South | `X^-1` |

All four are generated by the two verified physical translations.

## Interpretation for STAR

Each `[[448,64,7]]` block contains two disjoint 32-logical-qubit sectors, one
on each BB half.  Two code blocks, one for each checkerboard color, therefore
run two complete 64-site simulations in parallel.  Within each sector, the 32
logical fibres are disjoint and together cover one physical half, satisfying
the static support requirement for fully parallel STAR rotations.

This search certifies static code properties only.  Circuit fault distance,
ancilla scheduling, simultaneous-injection correlated faults, and
postselection performance remain to be simulated.  The principal tradeoff
against the row bicycle-chain code is the increase from weight-8 to weight-12
checks and from 56 to 448 physical qubits per factory block.
