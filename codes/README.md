# Reference codes

Code-centered studies keep constructions, matrices, logical bases, schedules,
certification records, and supporting searches together. Portable bundles retain
their internal layouts and standalone verifiers.

| Project | Purpose and status |
| --- | --- |
| [`certified_css_grid_codes/`](certified_css_grid_codes/README.md) | Portable 64- and 128-qubit code collection with exact verifier and manifests. |
| [`c4xc4_64_16_6_313c9898/`](c4xc4_64_16_6_313c9898/README.md) | Frozen 313c9898 reproducibility bundle, including schedules and certificates. |
| [`c4xc7_automorphism_dual_56_8_6/`](c4xc7_automorphism_dual_56_8_6/README.md) | BB56 construction and verification, with syndrome schedule. |
| [`c4xc8_abelian_lp_160_32_6/`](c4xc8_abelian_lp_160_32_6/README.md) | Connected 160-qubit automorphism-fold code and schedule. |
| [`c28xc4_component/`](c28xc4_component/README.md) | Extracted 112-qubit component, certification, and schedule-recovery records. |
| [`n32_k4_d6_reference_code/`](n32_k4_d6_reference_code/README.md) | Folded-ZX reference study, schedules, and circuit-fault analysis. |
| [`n36_k4_d6_coset2bga/`](n36_k4_d6_coset2bga/README.md) | Published coset-2BGA code and derived logical basis. |
| [`bicycle_chain_l2_paper/`](bicycle_chain_l2_paper/README.md) | Partial TMR source here; complete analysis on `bicycle-chain-l2-analysis`. |
| [`bicycle_chain_l4_paper/`](bicycle_chain_l4_paper/README.md) | Local artifacts here; implementation on `bicycle-chain-l4-postselection`. |
| [`n22_k2_d6_shortened_golay/`](n22_k2_d6_shortened_golay/README.md) | Local artifacts here; source on the BB64 and bicycle-chain development branches. |

Nested simulations remain with their reference code for this migration and are
also listed in the [simulation index](../simulations/README.md). Dedicated
313c9898 postselection experiments live under
[`simulations/c4xc4_313c9898_tmr_postselection/`](../simulations/c4xc4_313c9898_tmr_postselection/README.md).

For portable bundles, change into the bundle and follow its README. Historical
absolute paths in archived source, manifests, and provenance are retained;
the [path map](../docs/reorganization/path-map.json) records their new locations.
