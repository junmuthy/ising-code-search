# Bicycle-chain L2 study

The nested `tmr_postselection/` directory contains partial source on this branch. Full code data, schedules, and tests belong to the analysis branch.

Source is available on `bicycle-chain-l2-analysis`. The reorganization does not merge or
modify those branches. Before integrating one, translate its original root-level
project path using the [migration map](../../docs/reorganization/path-map.json)
and follow the [branch-integration notes](../../docs/reorganization/README.md).

Existing ignored artifacts remain local. Their presence does not imply a complete
runnable implementation in a clean checkout of this branch.
