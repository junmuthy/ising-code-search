# `[[112,16,7]]` exact-self-dual `C28 x C4` Ising component

The even- and odd-`C56` Tanner components of the weight-16
`[[224,32,7]]` candidate are isomorphic copies of this code.  After reindexing
one parity class, its physical group is `C28 x C4`.

## Polynomial presentation

Work over

\[
\mathbb F_2[u^{\pm1},v^{\pm1}]/(u^{28}-1,v^4-1).
\]

Define

\[
\begin{aligned}
s(u) &= 1 + u^4 + u^8 + u^{16},\\
s^\dagger(u) &= 1 + u^{12} + u^{20} + u^{24}.
\end{aligned}
\]

Translations of the following three seeds generate the complete rank-48
check space:

\[
\begin{aligned}
h_1 &= s(u)(1 + v + v^2 + v^3),\\
h_2 &= s(u)(1 + u^7 + u^{14} + u^{21}),\\
h_3 &= s^\dagger(u)(1 + u^{21})(1 + v).
\end{aligned}
\]

All three seeds have weight 16.  Their unique translation-orbit sizes are
`28`, `28`, and `112`; their individual orbit ranks are `12`, `12`, and `27`.
Together they have rank `48`.  This reduces the inherited six-seed
presentation to three seed types.

The CSS code uses the same binary row space for both check types:

\[
H_X = H_Z = H.
\]

Consequently it is exactly ZX self-dual, not merely ZX dual up to a
permutation.

## Certified parameters and logical structure

The multistaq qLDPC construction and independent binary checks give

\[
[[112,16,7]].
\]

Distance seven was certified by excluding logical representatives through
weight six; an explicit weight-seven fibre supplies the upper bound.

The 16 canonical logical fibres are

\[
\ell_{a,b}=u^a v^b(1+u^4+u^8+\cdots+u^{24}),
\qquad a,b\in C_4.
\]

They are pairwise disjoint, each has weight seven, their binary Gram matrix is
the identity, and they form a complete logical basis modulo the checks.
Translations by `u` and `v` induce the required logical `C4 x C4` grid.

## Exact check weights

An exact HiGHS feasibility calculation found no nonzero stabilizer of weight
at most 12.  Translation symmetry permits fixing one occupied coordinate, so
this test covers every nonzero orbit.  The check space is doubly even, ruling
out weights 13, 14, and 15.  Explicit weight-16 seeds exist.  Therefore

\[
\text{minimum nonzero check/stabilizer weight}=16.
\]

A full independent basis can be chosen from untranslated copies of the three
seed orbits, so every measured check can have weight exactly 16:

| Check weight | Independent checks per CSS type |
| ---: | ---: |
| `16` | `48` |

## Balanced independent basis and abstract schedule

A 50,000-trial deterministic basis search selected 48 independent weight-16
checks with qubit degrees from 4 through 9:

| Qubit degree | Qubits |
| ---: | ---: |
| `4` | `3` |
| `5` | `9` |
| `6` | `34` |
| `7` | `34` |
| `8` | `19` |
| `9` | `13` |

The average degree is `48*16/112 = 48/7`, approximately `6.857`, per CSS
type.  An explicit bipartite edge coloring schedules all 768 check-data CNOTs
for one CSS type in exactly 16 layers, with 48 CNOTs in every layer.  This
Tanner-edge depth is optimal because every check has degree 16.  It assumes
one ancilla per independent check and ignores hardware geometry, ancilla
preparation, readout, and circuit-level hook-error ordering.

## Ising properties

- exact transversal Hadamard because `H_X=H_Z`;
- transversal CNOT between identical component blocks because the code is CSS;
- 16 disjoint weight-seven logical supports for parallel STAR injection;
- logical `C4 x C4` translations generated by physical `u` and `v` shifts;
- doubly-even check space, so transversal phase gates preserve the stabilizer
  group (the precise logical phase convention follows from the odd
  weight-seven fibres);
- exact distance seven.

One component does not contain the full `C8 x C4` half-grid.  Two isomorphic
components are required, with the missing odd `C8` translation implemented as
their exchange.
