# One-block `C28` `[[28,4,>=6]]` search

## Target and construction

This search asks whether one can remove the two-block doubling of the
`[[56,8,6]]` bicycle-chain geometry and retain one four-logical-qubit row on
28 physical qubits.

Write

```text
C28 ~= C4 x C7
```

and let `H = rho(h)` be the binary circulant represented by
`h in GF(2)[C28]`.  The code is

```text
H_X = H_Z = H.
```

Consequently CSS orthogonality is exactly `h h^dagger = 0`, and
`rank(H)=12` gives `[[28,4,*]]`.

The order-four translation is `x^7`.  The four cosets of the order-seven
subgroup generated by `x^4` are pairwise-disjoint weight-seven logical
candidates.  Requiring even polynomial parity on each coset places all four
in the kernel.  Their self-pairing is odd and their mutual pairing is zero,
so they have exact identity ZX pairing.

## Exhaustive scope

The four parity equations reduce the polynomial space to `2^24 = 16,777,216`
elements.  The implementation exhausts that entire space at check weights 6,
8, 10, and 12, then quotients common cyclic translations and inversion.

```text
weight       considered   self-orthogonal   rank 12   canonical
6                45,892                 0          0           0
8               388,815             1,239      1,050          33
10            1,645,224                 0          0           0
12            3,795,932             7,252      6,580         143
```

There are 176 canonical rank-correct candidates.  All 176 satisfy:

- parameters `[[28,4,*]]`;
- `H_X=H_Z` and exact transversal Hadamard;
- four pairwise-disjoint weight-seven logical fibres;
- exact `C4` translation;
- full-rank identity logical ZX pairing.

Of these, 169 have a connected Tanner graph.

## Distance result

Every candidate was exhaustively screened for logical operators of weights
one through five.  None has distance at least six:

```text
first logical weight 2: 67 candidates
first logical weight 3: 52 candidates
first logical weight 4: 57 candidates
```

The first witnesses fall into three cyclic families:

```text
{0,14}             antipodal invariant pair       67
{0,7,14,21}        order-four orbit                57
{0,4,20} or
{0,4,12}           thickness-direction triplet    52
```

Thus the desired logical geometry is not the problem: it occurs in every
rank-correct code.  The obstruction is the additional small cyclic logical
submodule forced by the one-block, self-orthogonal circulant ansatz.

This is an exact negative for the stated polynomial weights and fibre-parity
constraints.  It does not rule out a non-circulant `28`-qubit self-dual CSS
code or a more general quasi-cyclic protograph.
