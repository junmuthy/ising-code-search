# One-block `C28` search

This isolated search tests a one-block weakly self-dual cyclic CSS code over

```text
C28 ~= C4 x C7.
```

For a group-circulant matrix `H = rho(h)`, it sets

```text
H_X = H_Z = H
```

and exhaustively requires:

- even polynomial parity in each of the four `C7` fibres;
- `h h^dagger = 0`;
- `rank(H) = 12`, giving `[[28,4,*]]`;
- check weight 6, 8, 10, or 12.

The logical translation is `x^7`, and the four candidate logical supports are
the cosets of the order-seven subgroup generated by `x^4`.

Run without overwriting an earlier result:

```bash
NUMBA_CACHE_DIR=/tmp/gala-numba-cache \
  .venv/bin/python -m c28_one_block.run_search \
  --run-name exhaustive-w6-12-full-v2
```

Results are saved under `results/c28-one-block/<run-name>/`.

The completed first search is reported in [`RESULTS.md`](RESULTS.md).
