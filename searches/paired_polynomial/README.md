# Original paired-polynomial searches and exact certification

Run these tools as modules from the repository root. Shared algorithms live in
`gala_search/`; the existing default output locations under `results/` are retained.

## Reports

- [RESULTS.md](RESULTS.md)

## Commands

- `certify_distance.py`: `.venv/bin/python -m searches.paired_polynomial.certify_distance --help`
- `certify_results.py`: `.venv/bin/python -m searches.paired_polynomial.certify_results --help`
- `collect_results.py`: `.venv/bin/python -m searches.paired_polynomial.collect_results --help`
- `run_search.py`: `.venv/bin/python -m searches.paired_polynomial.run_search --help`
