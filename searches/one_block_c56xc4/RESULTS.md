# First one-block `C56 x C4` ideal search

## Outcome

The first exact-self-dual search completed all 731 distinct ideals without an
unresolved distance.  It demonstrates that one-block `[[224,32,7]]` stabilizer
spaces with the desired disjoint `C8 x C4` logical fibres are abundant, but it
did not find one with a connected presentation generated entirely by physical
checks of weight at most 12.

| Exact distance | Distinct ideals |
| ---: | ---: |
| `2` | 3 |
| `3` | 2 |
| `4` | 287 |
| `6` | 243 |
| `7` | 196 |

Thus 439 ideals meet `d >= 6`, and 196 reach the fibre-imposed ceiling `d=7`.
No distance-five code occurred in this family.

## Scope

The physical group is `C56 x C4`.  The subgroup `<x^8> = C7` supplies the
seven-qubit thickness fibres, while the quotient supplies exact logical
`C8 x C4` translations.  Every candidate has:

- `n=224` and stabilizer rank 96;
- exactly `k=32` complete disjoint weight-seven logical fibres;
- `H_X = H_Z` and exact transversal Hadamard;
- transversal inter-block CNOT;
- identity logical ZX pairing.

The enumerated inputs were:

| Input family | Normalized inputs |
| --- | ---: |
| Monomial ideals in `GF(8)[U,V]/(U^8,V^4)` | 495 |
| Sparse monomial | 1 |
| Normalized binomials | 17 |
| Normalized zero-augmentation trinomials | 930 |

After duplicate ideal row spaces were merged, 731 distinct codes remained.
The sparse inputs reduce to 13 distinct binomial ideals and 238 distinct
trinomial ideals; some coincide with monomial ideals.

## Family-resolved distances

Families overlap when different inputs generate the same ideal.

| Family membership | `d=2` | `d=3` | `d=4` | `d=6` | `d=7` |
| --- | ---: | ---: | ---: | ---: | ---: |
| Monomial ideal | 2 | 2 | 277 | 114 | 100 |
| Binomial ideal | 3 | 0 | 6 | 4 | 0 |
| Trinomial ideal | 0 | 0 | 12 | 130 | 96 |

Trinomials are the strongest part of this first pass: 226 of 238 distinct
trinomial ideals have distance at least six.

## Weight-12 obstruction

The binary thickness simplex seed has weight four.  A quotient polynomial
with one, two, or three nonzero `GF(8)` coefficients therefore produces a
physical check of weight 4, 8, or 12.

For every ideal `I`, the construction needs sparse orbit generators for both
`I` and `Ann(I)`.  Only 11 of the 731 ideals could generate both sectors using
quotient support at most three:

| Exact distance | Sparse-sector codes |
| ---: | ---: |
| `2` | 3 |
| `3` | 2 |
| `4` | 6 |

All 11 have disconnected translated-check Tanner graphs.  Consequently:

```text
connected + maximum check weight 12 + distance at least 6: 0
```

The high-distance ideals generally have a sparse generator in one reciprocal
sector, while the complementary annihilator has no nonzero element of quotient
weight at most three capable of completing its ideal.  The failure is therefore
in the sparse measurement presentation, not in rank, ZX duality, logical
geometry, or distance.

## Exact distance method

Physical translations make all 32 fibre constraints equivalent.  Distance is
therefore the minimum weight of `e` satisfying

```text
H e = 0,   L_0 e = 1.
```

Weights one through five were searched exactly by subset-syndrome enumeration.
Remaining cases used an exact vectorized `3+3` meet-in-the-middle search for a
weight-six solution.  If none existed, the explicit weight-seven fibre supplied
the matching upper bound.  This left no unresolved candidates.

## Interpretation and next search

This result does not rule out a weight-12 one-block code over `C56 x C4`.
The first pass did not enumerate arbitrary ideals generated jointly by two or
more sparse deformed polynomials.  The most direct continuation at unchanged
check weight is therefore:

1. enumerate two-generator binomial/trinomial ideals;
2. retain only pairs for which the annihilator is also generated by quotient
   support at most three;
3. test connectivity before distance, using the present exact certificates as
   guidance;
4. separately search clean permutation-assisted ZX folds, which need not use
   the same ideal for `X` and `Z` checks.

Increasing quotient support to four would correspond to weight-16 checks, but
is not required for the next search tier.
