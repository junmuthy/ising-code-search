# Single-row searches and abelian/floating-dimension studies

Run these tools as modules from the repository root. Shared algorithms live in
`gala_search/`; the existing default output locations under `results/` are retained.

## Reports

- [ABELIAN_SINGLE_ROW_RESULTS.md](ABELIAN_SINGLE_ROW_RESULTS.md)
- [SINGLE_ROW_32_SEARCH.md](SINGLE_ROW_32_SEARCH.md)

## Commands

- `certify_single_row_floating.py`: `.venv/bin/python -m searches.single_row.certify_single_row_floating --help`
- `certify_single_row_remaining.py`: `.venv/bin/python -m searches.single_row.certify_single_row_remaining --help`
- `run_single_row_floating.py`: `.venv/bin/python -m searches.single_row.run_single_row_floating --help`
- `run_single_row_search.py`: `.venv/bin/python -m searches.single_row.run_single_row_search --help`
- `run_single_row_solved_g.py`: `.venv/bin/python -m searches.single_row.run_single_row_solved_g --help`
