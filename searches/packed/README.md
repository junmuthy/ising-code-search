# Packed 2D Ising-lattice searches

Run these tools as modules from the repository root. Shared algorithms live in
`gala_search/`; the existing default output locations under `results/` are retained.

## Reports

- [PACKED_RESULTS.md](PACKED_RESULTS.md)

## Commands

- `certify_packed.py`: `.venv/bin/python -m searches.packed.certify_packed --help`
- `run_packed_search.py`: `.venv/bin/python -m searches.packed.run_packed_search --help`
