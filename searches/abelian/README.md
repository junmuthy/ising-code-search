# Abelian 32-qubit and order-seven-fibre searches

Run these tools as modules from the repository root. Shared algorithms live in
`gala_search/`; the existing default output locations under `results/` are retained.

## Reports

- [ORDER_SEVEN_FIBRE_RESULTS.md](ORDER_SEVEN_FIBRE_RESULTS.md)

## Commands

- `certify_abelian_fibre.py`: `.venv/bin/python -m searches.abelian.certify_abelian_fibre --help`
- `run_abelian_32_search.py`: `.venv/bin/python -m searches.abelian.run_abelian_32_search --help`
- `run_abelian_fibre_search.py`: `.venv/bin/python -m searches.abelian.run_abelian_fibre_search --help`
