# Direct `C28 x C4` search for `[[112,16,d>=6]]`

This directory searches one-block weakly self-dual CSS ideals directly in

\[
\mathbb F_2[C_{28}\times C_4].
\]

It is independent of the earlier `C56 x C4` lift search.  The decomposition
`C28 = C7 x C4` exposes reciprocal `GF(8)[C4 x C4]` sectors.  An ideal and its
annihilator produce a rank-48 self-orthogonal binary check space, leaving the
trivial `C7` sector as 16 disjoint weight-seven logical fibres arranged as a
logical `C4 x C4` grid.

The first search enumerates all 70 nilpotent monomial ideals and every distinct
principal ideal generated by a normalized nonunit polynomial with at most
three `GF(8)` terms.  Such a term embeds as a weight-four simplex word, so the
physical stabilizer-weight ceiling is 12.

Unlike the earlier RREF audit, the connected-presentation test uses *every*
eligible sparse orbit generator in each ideal before extracting a smaller
presentation.  Exact distance is determined through weight six; a canonical
logical fibre supplies the weight-seven upper bound.

Run with the project environment:

```bash
/home/judah_unmuth/gala-code-search/.venv/bin/python run_search.py \
  --output /home/judah_unmuth/gala-code-search/results/c28xc4-direct-d6-w12-v1
```

The runner refuses to overwrite an existing output directory and writes an
atomic `progress.json` checkpoint every ten candidates.

After the first pass, exactly complete every distance-six stabilizer space
through physical weight 12 with:

```bash
/home/judah_unmuth/gala-code-search/.venv/bin/python complete_weight12.py \
  --source /home/judah_unmuth/gala-code-search/results/c28xc4-direct-d6-w12-v1 \
  --output /home/judah_unmuth/gala-code-search/results/c28xc4-direct-d6-w12-completion-v1
```

The mixed-sector completion uses a HiGHS MILP and also proves whether a light
check capable of connecting a proper displacement subgroup exists.

Extract the selected connected weight-16 representative, its balanced
independent basis, and two explicit optimal Tanner-edge schedules with:

```bash

  --output /home/judah_unmuth/gala-code-search/results/c28xc4-direct-d6-w16-representative-v1
```
