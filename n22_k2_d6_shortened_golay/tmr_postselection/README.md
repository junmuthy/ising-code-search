# `[[22,2,6]]` TMR post-selection simulation

This package repeats the post-selection-only small-angle resource-state
experiment previously run for the `[[64,8,8]]` code.  It stops immediately
after the post-TMR syndrome round: logical teleportation, decoding, and
fidelity estimation are deliberately outside this experiment.

## Frozen inputs

The simulation loads the saved `[[22,2,6]]` presentation and its optimal
eight-layer simultaneous syndrome schedule without regenerating either:

- code archive SHA-256:
  `63bd3c293318c7c3166177fd774effe5533b379b7d9d2ac7058251ff70c9f00b`;
- schedule SHA-256:
  `dc8168ebfcc6e7f63df2cf841a388fbe1fe69f7d0cdf3bdbd499639374f609b4`;
- disjoint logical-Z supports:
  `{0,1,3,4,5,9,11}` and `{2,7,8,12,15,16,17}`.

`partitions_m3.json` splits each weight-seven logical support as `2+2+3`.
The six partial operators have X-syndrome rank four and kernel dimension two.
That kernel is exactly generated by taking all three pieces of either logical,
so no unintended proper partial product passes the one final projection.

## Circuit and noise model

The implementation intentionally matches the BB64 experiment:

- `M=3` TMR with the same physical-angle convention;
- transversal physical `|+>` initialization;
- one scheduled Z-only initialization round and virtual X-frame correction;
- noisy CNOT ladders for the six partial rotations;
- one scheduled post-TMR round containing all displayed X and Z checks;
- preparation, measurement, one-qubit rotation, two-qubit gate, and
  entangling-layer idle noise at the same probability `p`.

Because the two logical-Z representatives are mutually disjoint, they form one
parallel TMR batch.  “Check after each batch” and “one final check” are therefore
the same physical circuit for this code.

The full two-logical circuit uses:

- 22 data qubits and 22 dedicated syndrome ancillas;
- 280 physical CNOTs;
- 20 entangling layers (8 initialization, 4 TMR ladders, 8 final syndrome);
- 6 physical single-qubit rotations;
- 22 final post-selection outcomes, plus one initialization consistency
  detector that catches the single displayed Z-check redundancy.

```bash

/home/judah_unmuth/Documents/multistaq/star-simulators/.venv-clifft/bin/python \
  -m n22_k2_d6_shortened_golay.tmr_postselection.select_partitions \

```

The version-controlled manifests reproduce the ideal sweep, the primary
one-million-shot noisy point, and the 13-point full-circuit angle sweep from
`1` to `10^-3` radians.  `plot_angle_sweep.py` regenerates the SVG, CSV, and
Markdown sweep summaries without external plotting dependencies.  Raw result
JSON and Stim files live under the ignored `results/` directory.  The runner
checkpoints atomically and prints progress after every shot batch.

## Interpretation

For `N` rotated logicals and observed block acceptance `s`, the reported
candidate-resource yield is

\[
Y_{\mathrm{candidate}}=Ns.
\]

An accepted block has passed the stabilizer projection for both candidate
resource states.  Acceptance alone does not certify their logical fidelity;
that requires the later teleportation/observable experiment.
