# `C28 x C4` exact-self-dual Ising component

This directory constructs and certifies the parity component extracted from
the `C56 x C4` one-block search.  It is a `[[112,16,7]]` CSS code with
`H_X=H_Z`, 16 disjoint weight-seven logical fibres, and logical translation
group `C4 x C4`.

The physical group algebra is

```text
F2[u^+-1,v^+-1]/(u^28-1,v^4-1).
```

Define

```text
s(u)         = 1 + u^4  + u^8  + u^16,
s_dagger(u)  = 1 + u^12 + u^20 + u^24.
```

The complete check space is generated by translations of only three
weight-16 polynomials:

```text
h1 = s(u)        (1 + v + v^2 + v^3),
h2 = s(u)        (1 + u^7 + u^14 + u^21),
h3 = s_dagger(u) (1 + u^21) (1 + v).
```

The logical fibres are

```text
ell_(a,b) = u^a v^b (1 + u^4 + u^8 + ... + u^24),
a,b in C4.
```

Run the analysis with the project virtual environment:

```bash
../.venv/bin/python c28xc4_component/run_analysis.py \
  --output results/c28xc4-component/NAME
```

The separate `certify_minimum_check.py` MILP proves that no stabilizer of
weight at most 12 exists.  Because the check space is doubly even and explicit
weight-16 checks exist, this certifies minimum check weight 16.
